# Spinfinity

Spinfinity is a Python package for simulating quantum spin systems in tunnel junction experiments.

## Features
Spinfinity provides tools to construct multi-spin Hamiltonians, compute eigenstates and transition rates, and simulate observables such as IETS and ESR spectra.
