# Spinfinity

Spinfinity is a Python package for simulating quantum spin systems in tunnel junction experiments.

## Features
Spinfinity provides tools to construct and solve multi-spin Hamiltonians, compute transition rates induced by electron tunneling from electron reservoirs in second order perturbation theory, and simulate IETS and ESR spectra.
