# Spinfinity

## Description

Spinfinity is a Python package for simulating quantum spin systems in
tunnel-junction experiments in Scanning Probe Microscopy. 
It provides tools to build multi-spin Hamiltonians, 
calculate eigenstates and transition rates, and simulate
observables related to the tunneling current such as Inelastic Electron 
Tunneling Spectrocopy or Electron Spin Resonance

## Installation
The authors recommend to install the "spinsimulation" package to a python
environment. Create and activate a Python environment with Python 3.10 or newer, 
then install the package from the project root:

```bash
conda install jupyter pip
cd folderpath 
pip install -e .  
```

The Spinfinty project comes with a documentation using the mkdocs package.
Install it to your environment via:

```bash
cd folderpath 
pip install .[docs]  
```

To generate the local documentation website run:

```bash
mkdocs serve
```
You can then access the documentation via the URL provided.
